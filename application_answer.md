## Project Name
AI-Powered RFQ-to-Supplier Matching & Lead Prioritization

## Brief Description
Built an independent B2B marketplace prototype that converts unstructured buyer RFQs into structured requirements, predicts buyer intent, ranks relevant suppliers and prioritizes leads for sales action. The solution combines NLP-based intent classification with explainable supplier matching using product similarity, specifications, capacity, location, lead time and supplier reliability. I also implemented SQL analytics and a Streamlit interface to demonstrate the complete product workflow.

## AI/ML Technologies/Tools
Python, Pandas, NumPy, Scikit-learn, TF-IDF, Logistic Regression, cosine similarity, Streamlit and SQL.
