# CV Bullets

## Balanced
- Built an AI-powered B2B RFQ intelligence prototype using NLP and supplier matching to extract requirements, predict buyer intent, rank suppliers and prioritize leads through an explainable scoring framework.

## Product-focused
- Designed an end-to-end B2B marketplace product workflow from RFQ submission to supplier recommendation, defining user stories, KPIs, prioritization logic and human-in-the-loop feedback.

## Analytics/AI-focused
- Developed a Python/Scikit-learn NLP pipeline for RFQ intent classification and a hybrid supplier-ranking engine combining semantic similarity with structured capability, location, capacity and lead-time signals.
